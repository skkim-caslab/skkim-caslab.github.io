Seulki Kim 김슬기

Ph.D. Student, DGIST · Member of CASLAB@Yonsei

I design hardware that brings computation to where the data lives.

My work makes sparse LLMs run on processing-in-memory, lets vector search stream from DRAM banks, and helps on-device NPUs use every byte of on-chip memory.

LLM decoding and billion-scale vector search are limited by memory bandwidth, not arithmetic. I co-design data layouts and the hardware that consumes them, so compressed and sparse data streams at full bandwidth.

SMOOTH

Hardware-Assisted Fine-Grained On-Chip Memory Management for Efficient On-Device LLM Inference

Decoding leaves DRAM bandwidth idle in short bursts; SMOOTH fills them by managing the NPU scratchpad at runtime.

S-ANNS

Energy-Efficient Approximate Nearest Neighbor Search via Shift-Based PIM Architecture

Database vectors never change, so S-ANNS does the multiplier’s recoding offline and the PIM only shifts and adds.

1.4–1.9×search throughput at 0.3–0.7× footprint
−49.4%PE area vs FP32 MAC
−58.9%PE power vs FP32 MAC
Project

BlockPIM

Enabling Sparse LLM Inference on Dense PIM Architectures

Pruning aligned to the PIM’s 32-byte I/O lets sparse LLMs run on the dense pipeline with only a bitmap as metadata.
